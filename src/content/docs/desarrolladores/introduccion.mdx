La **API pública** de Snappli te permite leer datos de tu organización (hoy, contactos) desde tus propios sistemas. Para eventos en tiempo real usa [webhooks](/desarrolladores/webhooks/).

## Requisitos

- El plan **Pro** o superior de Snappli completo (Pro, Business o Enterprise), que incluye **API y webhooks**.
- Una **API key** creada en **Configuración → API**.

## Base URL

```
https://api.snappli.io/api
```

Todas las rutas públicas cuelgan de `/api/v1`.

## Arranque rápido

<Steps>

1. Crea una API key en **Configuración → API**.
2. Autentica con `Authorization: Bearer sk_…` — ver [Autenticación](/desarrolladores/autenticacion/).
3. Llama a los [endpoints de contactos](/desarrolladores/contactos/).
4. Suscribe [webhooks](/desarrolladores/webhooks/) si necesitas eventos.

</Steps>

## Referencia interactiva

Dentro de la app, **Configuración → API** incluye una referencia interactiva (OpenAPI + Scalar) donde puedes probar peticiones con tu clave. Esta documentación cubre conceptos, autenticación, endpoints y webhooks.

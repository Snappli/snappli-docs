La **API pública** de Snappli te permite leer datos de tu organización desde tus propios sistemas: contactos y, para depurar tus integraciones, los webhooks con su historial de entregas y los conectores con sus llamadas. Para eventos en tiempo real usa [webhooks](/desarrolladores/webhooks/), y para que la IA consulte o actúe en tu sistema durante la conversación, [conectores](/desarrolladores/conectores/).

## Requisitos

- El plan **Pro** o superior de Snappli completo (Pro, Business o Enterprise), que incluye **API y webhooks**.
- Una **API key** creada en **Configuración → API**.

## Base URL

```
https://api.snappli.io/api
```

Todas las rutas públicas cuelgan de `/api/v1`:

| Endpoint | Permiso |
|---|---|
| `GET /v1/me` | Cualquiera |
| `GET /v1/contacts`, `GET /v1/contacts/:id` | `contacts:read` |
| `GET /v1/webhook-integrations`, `GET /v1/webhook-integrations/:id`, `POST /v1/webhook-integrations/:id/mapping-preview` | `webhooks:read` |
| `GET /v1/webhook-deliveries`, `GET /v1/webhook-deliveries/:id` | `webhooks:read` |
| `POST /v1/webhook-integrations/:id/test`, `POST /v1/webhook-deliveries/:id/retry` | `webhooks:test` |
| `GET /v1/connectors`, `GET /v1/connectors/:id`, `GET /v1/connectors/:id/logs` | `connectors:read` |
| `POST /v1/connectors/:id/operations/:operationId/test` | `connectors:test` |

## Arranque rápido

<Steps>

1. Crea una API key en **Configuración → API** con los [permisos](/desarrolladores/autenticacion/#permisos) que necesites.
2. Autentica con `Authorization: Bearer sk_…` — ver [Autenticación](/desarrolladores/autenticacion/).
3. Llama a los [endpoints de contactos](/desarrolladores/contactos/).
4. Suscribe [webhooks](/desarrolladores/webhooks/) si necesitas eventos.
5. Prueba tu receptor en local con el [CLI](/desarrolladores/herramientas/): `npx @snappli/cli webhooks trigger contact.stage.entered --to http://localhost:3000/webhooks/snappli --repeat`.

</Steps>

Si trabajas con un agente (Claude Code, Cursor, Codex), dale el [servidor MCP y la skill](/desarrolladores/herramientas/#con-tu-agente) de Snappli.

## Referencia interactiva

Dentro de la app, **Configuración → API** incluye una referencia interactiva (OpenAPI + Scalar) donde puedes probar peticiones con tu clave. Esta documentación cubre conceptos, autenticación, endpoints y webhooks.

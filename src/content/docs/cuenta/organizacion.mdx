Los ajustes de la organización están en **Configuración → General** (`/manage/organization/settings`).

## Ajustes generales

- **Nombre y logo** de la organización.
- **Zona horaria** de referencia.
- **Tiempo de inactividad** de conversaciones (15 / 30 / 60 min).
- **Resumen semanal** por email.
- **Teléfonos de QA** (solo Propietario).

## Otras áreas de configuración

| Área | Dónde | Para qué |
|------|-------|----------|
| **Campos de contacto** | Configuración → Campos de contacto | Campos personalizados del CRM |
| **Etiquetas de contacto** | Configuración → Etiquetas de contacto | Clasificar contactos |
| **Etiquetas de inbox** | Organización → Etiquetas | Clasificar conversaciones |
| **Pipeline** | Configuración → Pipeline | Etapas y acciones |
| **API** | Configuración → API | API keys y referencia interactiva |
| **Webhooks** | Configuración → Webhooks | Eventos hacia sistemas externos |

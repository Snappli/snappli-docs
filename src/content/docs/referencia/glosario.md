  order: 1
---

| Término | Definición |
|---------|------------|
| **Organización** | Tenant: tu empresa en Snappli |
| **Canal** | WhatsApp, Instagram, Messenger, email o widget |
| **Contacto** | Persona o lead en el CRM |
| **Conversación** | Hilo de mensajes con un contacto en un canal |
| **Agente** | Usuario humano del inbox |
| **Asistente / Agente IA** | Bot con instrucciones y base de conocimiento |
| **Base de conocimiento** | Documentos indexados que usa la IA para responder |
| **Escalación** | Paso de la IA al equipo humano |
| **Pipeline** | Embudo de etapas para contactos |
| **Acción de etapa** | Automatización al entrar a una etapa del pipeline |
| **Etiqueta** | Label de inbox o de contacto para filtrar |
| **Departamento / cola** | Agrupación para enrutar conversaciones |
| **Campaña** | Envío o secuencia hacia contactos |
| **API key** | Secreto `sk_…` para la API pública |
| **Webhook** | Notificación HTTP saliente hacia tu sistema |
| **Add-on** | Extra de billing (capacidad o funciones) |
| **Manage** | Área de administración (canales, billing, desarrolladores…) |
